# Robo-Adviser
# AI로보어드바이저(ChatGPT)를 활용한 금융 추천 서비스 개발

### 🌳 로보어드바이저란?

로봇(Robo) + 자산관리 전문가(Advisor)의 합성어로 인공지능과 알고리즘을 활용해 자동으로 투자 포트폴리오를 구성하고 관리해주는 디지털 자산관리 서비스

### 🌳 목표

- 사람들이 쉽고 빠르게 투자에 접근할 수 있도록 하는 것
- 어려운 투자 용어나 투자 방법에 대해서도 거부감 없게 활용할 수 있는 서비스를 만드는 것

→ 스마트폰 앱을 통한 서비스 제공

### 🍃 AI 알고리즘

1. **주가 예측 알고리즘**
- LSTM 모델 + yfinance 라이브러리 활용
- 주가, 환율 반영
- 성능 개선 → 네이버에서 금융 뉴스 기사를 크롤링하여 기업의 현재 상황을 분석하여 기업 이미지 (긍정:1, 부정:0) 으로 정량적 지표를 추가하여 활용
- 예측 모델의 결과가 상승하고, 실제 주가 또한 상승하면 사용자에게 추천하기로 결정

1. **추천 알고리즘**
- 사용자 관련 정보 로그인 시 설문조사를 통해 수집
- 수집 데이터 종류: 성별, 연령대, 직업, 평균소득, 자산규모, 자산유형, 투자성향, 투자목적, 이해수준
- 총 4개의 그룹으로 클러스터링 진행 → 안정형, 저위험형, 중위험형, 고위험형
- 클러스터링 진행 시 투자성향에 가중치를 부여하여 진행
- 사용자 투자 성향과 일치는 금융 상품 매칭

1. **생성형 AI**
- 최신 금융 트렌드 및 금융 기사 제공
- 사용자의 간단한 질문 답변 챗봇 서비스 제공

### 🙂 결과

- 데이터 정규화 및 학습을 통해 기존 모델 Loss 0.5215에서 0.0061까지 성능 개선
- 최종 앱 구현 성공
